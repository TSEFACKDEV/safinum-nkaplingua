## 10ter. Corrections UX appliquées

- **Statuts honnêtes** : les trois langues affichent « brouillons non validés » ;
  le moteur est nommé `Pack + MT` (fub, ewo) ou `Pack` (dua), plus de
  « phrases validées ».
- **Actions réelles** : le content script répond après la traduction, la
  restauration ou la sélection ; le popup distingue succès, no-op et erreur.
  Les boutons sont désactivés pendant l'action (`aria-busy`).
- **État de page** : `NK_GET_STATE` expose page traduite, langue, compteurs,
  partiels et troncature. Changer de langue après traduction restaure puis
  retraduit automatiquement.
- **Cloud visible** : le pied affiche « Cloud MyMemory · pseudonymisé » quand
  l'opt-in est actif ; il ne dit plus « Local » dans ce cas.
- **Grand public** : les erreurs de sélection/pack/critique ne montrent plus de
  chemins `data/language-packs` ni de « niveau A ».
- **Langue du popup** : `ui-copy.js` suit `<html lang>` du site ; site FR →
  popup FR, site EN → popup EN. Les libellés, statuts, test et confidentialité
  sont traduits.
- **Accessibilité** : actions secondaires et options de langue à 44 px,
  checkbox 16 px, libellé 44 px, erreur de test inline, focus conservé.
- **Langue** : le popup et les toasts/notes de la page suivent désormais
  `<html lang>` (FR/EN) ; les erreurs de sélection sont localisées.

Vérifications : `tests/state.test.js`, `tests/ui-language.test.js`,
`tests/error-taxonomy.test.js`, popup 380×600 (461 px fermé, 667 px test,
792 px confidentialité), site **222 passages**, 0 erreur.
