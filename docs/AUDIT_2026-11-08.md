# Audit d’exécution et de recette — 8 novembre 2026

**Branche auditée** : `develop` à `38bba51` (merge PR #15, après K10/K11).
**Objet** : vérifier l’état réel du produit après les avancées de Freedy,
Klein et Marius, puis exécuter un test de bout en bout avec le vrai backend
NLLB, la vraie extension et le site de test SAFINUM.

**Verdict général** : la base logicielle est saine et les garde-fous
fonctionnent, mais **la démonstration réelle n’est pas au niveau annoncé**.
Sur l’étape 1 du site, le backend NLLB réel ne traduit que **6 segments sur
44** et laisse **38 segments en français**. Les tests mock/CI ne mesurent pas
cette limite.

## 5. Vingt phrases inédites — test réel

Les 20 phrases de `data/unseen_finance.txt` ont été envoyées au **vrai
background** de l’extension, puis au vrai NLLB.

| Mode | Acceptées | Refusées | Détail |
|---|---:|---:|---|
| Production (`demo:false`) | **1/20 (5 %)** | 19 | 12 `untranslated_critical`, 2 `token_lost`, 5 `low_roundtrip` |
| Démo (`demo:true`) | **4/20 (20 %)** | 16 | 12 `low_roundtrip`, 3 `token_lost`, 1 `too_short` |

La barre annoncée dans le README (« 12 acceptées sur 20 ») n’est **pas
reproduite** avec le backend NLLB réel de ce poste : on obtient 1/20 en
production et 4/20 en mode démo. La différence doit être expliquée avant de
communiquer un chiffre au jury.

Les sorties acceptées restent parfois approximatives :

- « Vous avez déjà épargné 45 000 FCFA… » → « On ɗon maɓɓina 45 000 FCFA… »
  (sens partiellement conservé, style brouillon) ;
- « Le compte peut être fermé… » → « Jaɓɓorgo Ganndal ngal ina waawi
  ɓaggeede… » (lexique administratif approximatif) ;
- plusieurs phrases sont refusées pour `low_roundtrip` alors que la
  traduction était au moins partiellement utilisable.

## 6. Site SAFINUM — étape 1 en réel

Le content script injecté sur `https://safinum.cm/hackathon-test` a produit
le toast final suivant :

> Mode démo SAFINUM (données fictives) — **6 segment(s) traduits** en

> **38 non traduit(s)** · **2 critique(s) en MT démo non validée**).

Autres mesures :

| Mesure | Résultat |
|---|---:|
| Segments traduits annoncés | 6 / 44 |
| Marqueurs `lang="fub"` | 5 |
| Marqueurs `data-nk-demo-critical="A"` | 2 |
| Marqueurs `data-nk-untranslated="A"` | 0 |
| Erreurs page / console | **0** |
| Boutons avant/après | identiques |
| Montants `250 000` et `12 500` FCFA | préservés |
| Restauration (1,5 s) | texte identique, marqueurs à 0 |
| Restauration (0,8 s) | échec du contrôle : DOM non stabilisé, à re-tester avec attente d’événement |

**Défauts visibles dans le rendu** :

- `Bonjour, Amina` devient `hello, amina` : mélange anglais, nom minusculé.
- `Numéro de compte : CM 001 2345 6789 01` devient
  `Numero account: CM 001 23456789 01` : **un espace du numéro de compte
  disparaît** dans l’occurrence traduite. L’occurrence non traduite du panneau
  latéral reste intacte, ce qui masque le défaut si on cherche seulement la
  chaîne d’origine dans le body.
- 38 segments restent en français : la page n’est pas une démonstration
  complète en fulfulde.

Ce résultat est très en dessous du test documenté
`docs/SITE_TEST_SAFINUM.md` (66/71 acceptés), qui utilise `flagship-ai` et
MyMemory. Ces modèles ne sont pas présents dans l’environnement audité ; le
fallback NLLB seul est nettement plus faible.

## 7. Popup et messages d’erreur

- Les 3 langues sont bien présentes : Fulfulde, Ewondo, **Duala**.
- Une phrase critique (« Le solde minimum… ») est correctement bloquée :
  message explicite, aucun appel MT.
- Une phrase non critique (« Le service client est disponible. ») est refusée
  par le backend pour `low_roundtrip:0.17`, mais le popup affiche :
  « Traduction refusée par le contrôle de sûreté : montants, noms ou entités
  non préservés. »
  **Le message est faux** : le problème est la qualité de la rétro-traduction,
  pas la préservation des entités. Il faut distinguer `low_roundtrip`,
  `token_lost`, `too_short` et `dnt_missing`.
- Les packs ewondo/duala sont vides (`0/20` validés chacun) : le niveau A ne
  peut pas être démontré dans ces deux langues.

## 8. Constats priorisés

### P0 — bloquants pour la démo

1. **Couverture réelle insuffisante** : 6/44 segments sur l’étape 1 ; 38
   restent en français. Le site n’est pas utilisable en fulfulde de bout en
   bout avec le backend NLLB seul.
2. **Qualité NLLB insuffisante** : 1/20 en production, 4/20 en démo ; sorties
   parfois hors sujet. Le chiffre « 12/20 » du README n’est pas reproduit.
3. **Préservation des entités incomplète** : numéro de compte sans espace,
   nom minusculé, jeton `[[NAME_0]]` perdu.

### P1 — importants

4. **Message d’erreur trompeur** dans le popup pour `low_roundtrip`.
5. **Packs ewondo/duala vides** : aucune phrase validée, donc aucun niveau A
   dans deux des trois langues.
6. **Docs et tests divergent du réel** : `SITE_TEST_SAFINUM.md` et le README
   décrivent des résultats `flagship-ai`/MyMemory non reproduits ici ;
   `docs/test-results/README.md` indique encore `unseen/demo` comme bloqués.

### P2 — qualité et méthode

7. **`jsdom` n’est pas installé par défaut** sur le poste ; trois tests
   échouent sans `npm install --no-save jsdom`. La CI l’installe, mais le
   README local doit le rappeler.
8. **NLLB `fuv_Latn` est du fulfulde nigérian**, pas de l’Adamawa ; c’est un
   brouillon, sous licence CC BY-NC 4.0.
9. **Restauration** : le contrôle à 0,8 s est instable ; utiliser un événement
   ou un `waitForFunction` plutôt qu’un délai fixe.
10. **Étapes 2 à 5** : non rejouées en NLLB réel dans cet audit ; le test mock
    de `docs/SITE_TEST_SAFINUM.md` les couvre, mais pas la qualité réelle.
