# Fiches de syntaxe — fulfulde, ewondo, duala

**Statut** : fiches de travail, pas une grammaire validée. Les exemples viennent
des packs et des dictionnaires fournis. Chaque règle doit être confirmée par un
natif avant d'être présentée comme une règle de production.

## 1. Fulfulde (Adamawa)

### Ordre observé

- Libellé : `Solde disponible → Jawdindi ndi yami`.
- Groupe nominal : `Frais de transfert → Njoɓdi nawgol` (nom + complément).
- Possession : `Votre compte → Asaaku ma` (nom + possessif après le nom).
- Total : `Total débité → Kawral kaalis yoɓaaɗo` (nom + nom + participe).
- Action : `Envoyer → Nelu` ; `Continuer → Wontu yeeso` (verbe + direction).
- Phrase : `Le solde est de 25 000 FCFA → Jawdindi ko 25 000 FCFA`.

### À vérifier

- place de l'adjectif et du démonstratif ;
- accord de classe du nom et du possessif ;
- marque de la négation (`Ko yoɓataa`, `alaa`, `si…`) ;
- question : particule et ordre ;
- politesse : `Jam tiiɗi` (bonjour), formule de remerciement.

**Hypothèse de travail** : le nom porte souvent le possessif après lui ; le
verbe se place avant son complément dans les impératifs courts. À confirmer.

## 2. Ewondo

### Ordre observé

- `Bonjour → Mbolani`.
- `Solde disponible → Abálá é ne ngə́lə́` (nom + copule + état).
- `Frais de transfert → Mákyé má nkus` (nom + associatif `má`).
- `Banque en ligne → Banke á internet` (associatif `á`).
- `Votre compte a été crédité… → Kɔ́ndó wō á nnyɔ́ŋya…` (nom + possessif +
  associatif + verbe).
- `Confirmer le transfert → Sínyí nkus` (verbe + objet).

### À vérifier

- classes nominales et préfixes ;
- accord du possessif (`wō`, `má`, `é`) ;
- négation : `a tékə́` (ne pas / jamais) dans les exemples du pack ;
- question : `za` / intonation ;
- politesse : `Mbolani`, `Mbolani, Amina`.

**Hypothèse de travail** : l'associatif `á` relie deux noms ; le possessif suit
le nom. À confirmer par un natif.

## 3. Duala

### Ordre observé

- `Bonjour → Ã mbɔti`.
- `Solde disponible → Mɔ̀nì mwé ɓáyí` (nom + modificateur).
- `Frais de transfert → Móǹgá mwa lómo mɔ̀nì` (nom + associatif `mwa` + nom).
- `Banque en ligne → Banke a internet` (associatif `a`).
- `Référence → Nombara a lómo mɔ̀nì`.
- `Confirmer le transfert → Adise lómo mɔ̀nì` (verbe + objet).
- `Continuer → Kɛ́ oboso` ; `Retour → Timbia ombusa`.

### À vérifier

- classes nominales et préfixes (`mɔ̀nì`, `móǹgá`, `kompa`) ;
- associatif `a` / `mwa` et accord ;
- négation (`si`, `te`, autre) : aucun exemple fiable dans le pack ;
- question : `nje`, `nɛ`, intonation ;
- politesse : `Ã mbɔti`, `Idiba`.

**Hypothèse de travail** : l'associatif relie les noms et le verbe précède
l'objet dans les impératifs. À confirmer.

## 4. Fiche commune : ce qu'il faut relire

| Point | Question à poser au natif |
|---|---|
| Ordre | Le nom, le verbe et le complément sont-ils dans le bon ordre ? |
| Possession | Le possessif est-il après le nom ? S'accorde-t-il ? |
| Négation | La négation porte-t-elle sur le verbe ou sur le nom ? |
| Question | Particule, intonation ou ordre inversé ? |
| Politesse | La formule est-elle adaptée à un agent, un client, un aîné ? |
| Verbe | Impératif, infinitif, accompli : la forme est-elle naturelle ? |
| Accord | Classe nominale, nombre, personne. |

## 5. Limite

Ces fiches ne permettent pas de composer une phrase nouvelle de façon fiable.
Elles servent à **relire** les 50 phrases du kit et à repérer les constructions
suspectes. La validation reste humaine.
