Le backend local est prioritaire. MyMemory n’est utilisé que si vous l’autorisez explicitement ci-dessous : dans ce cas, montants, URLs, emails et noms de bénéficiaires sont remplacés par des jetons. Aucun mot de passe, code PIN, OTP ou valeur de formulaire n’est lu. Pour un usage réel, lancer le backend NLLB local.

Les packs communautaires contiennent des brouillons humains (fulfulde, ewondo, duala) mais aucune phrase validée pour l'instant. En mode strict, seules les phrases `validated` sont appliquées ; en mode démo SAFINUM, les brouillons `draft` et `reviewed` sont appliqués avec un badge explicite. Le duala ne contacte aucun service cloud.
