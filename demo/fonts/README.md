# Polices

Ces fichiers sont des sous-ensembles WOFF2 de polices libres :

- **Noto Sans** — SIL Open Font License 1.1
  https://fonts.google.com/noto/specimen/Noto+Sans
- **Fraunces** — SIL Open Font License 1.1
  https://fonts.google.com/specimen/Fraunces

Les fichiers `latin-ext` couvrent les caractères étendus nécessaires au
fulfulde (`ɓ`, `ɗ`, `ƴ`, `ŋ`) lorsque la police principale ne les contient pas.
